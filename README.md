# Mood Picker

A simple React project built with Vite where users can select their current mood. The app updates the background color and displays the selected mood dynamically.

##  Tech Stack

* React
* Vite
* JavaScript
* CSS

##  Features

* Select a mood
* Dynamic background color
* Interactive UI using `useState`

##  Run the Project

npm install
npm run dev

Built while learning React fundamentals.
